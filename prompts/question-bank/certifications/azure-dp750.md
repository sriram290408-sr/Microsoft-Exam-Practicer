# Certification Overview: Azure Databricks Data Engineer Associate (DP-750)

- **Platform**: Microsoft Azure
- **Exam Code**: DP-750
- **Target Audience**: Azure data engineers building enterprise pipelines with Azure Databricks, Unity Catalog, Entra ID, and Azure Data Factory.
- **Duration**: 100 Minutes
- **Question Format**: 100 questions in practice bank
- **Passing Score**: 700 / 1000 (70%)

## Objectives Breakdown
1. Set Up and Configure an Azure Databricks Environment (15–20%)
2. Secure and Govern Unity Catalog Objects (15–20%)
3. Prepare and Process Data with Apache Spark & Delta Lake (30–35%)
4. Deploy and Maintain Data Pipelines and Workloads (30–35%)
