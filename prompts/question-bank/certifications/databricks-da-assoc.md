# Certification Overview: Databricks Certified Data Analyst Associate

- **Platform**: Databricks
- **Exam Code**: DA-ASSOC
- **Target Audience**: Data analysts querying Lakehouses, building AI/BI dashboards, orchestrating Genie spaces, analyzing query execution profiles, and modeling data using Databricks SQL Warehouses.
- **Duration**: 90 Minutes
- **Question Format**: 45 questions on real exam / 100 questions in practice bank
- **Passing Score**: 70%

## Objectives Breakdown
1. Databricks Data Intelligence Platform Architecture (11%)
2. Managing Data with Unity Catalog (8%)
3. Importing Data (Delta Sharing, Cloud Storage) (5%)
4. Executing Queries Using Databricks SQL (20%)
5. Analyzing Queries & Query Profile (15%)
6. Working with Dashboards and Visualizations (16%)
7. Developing & Maintaining AI/BI Genie Spaces (12%)
8. Data Modeling with Databricks SQL (5%)
9. Securing Data & Dynamic Masking (8%)
