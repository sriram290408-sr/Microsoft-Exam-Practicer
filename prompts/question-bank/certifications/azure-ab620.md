# Certification Overview: Microsoft Certified: AI Agent Builder Associate (AB-620)

- **Platform**: Microsoft Copilot Studio & Power Platform
- **Exam Code**: AB-620
- **Target Audience**: Solution architects and developers designing, building, and deploying enterprise AI agents using Copilot Studio and Power Platform.
- **Duration**: 100 Minutes
- **Question Format**: 100 questions in practice bank
- **Passing Score**: 700 / 1000 (70%)

## Objectives Breakdown
1. Plan and Configure Agent Solutions (Topics, Triggers, Knowledge) (30–35%)
2. Integrate and Extend Agents (Power Automate, Connectors, MCP) (35–40%)
3. Test, Evaluate, and Manage Agent Lifecycle / ALM (25–30%)
