# Certification Overview: Azure AI Apps and Agents Developer Associate (AI-103)

- **Platform**: Microsoft Azure AI
- **Exam Code**: AI-103
- **Target Audience**: Software engineers developing generative AI applications, agentic workflows, and document intelligence systems in Microsoft Foundry.
- **Duration**: 100 Minutes
- **Question Format**: 100 questions in practice bank
- **Passing Score**: 700 / 1000 (70%)

## Objectives Breakdown
1. Plan and Manage an Azure AI Solution in Microsoft Foundry (25–30%)
2. Implement Generative AI and Agentic Solutions (30–35%)
3. Implement Computer Vision Solutions (10–15%)
4. Implement Text Analysis Solutions (10–15%)
5. Implement Information Extraction & Document Intelligence (10–15%)
