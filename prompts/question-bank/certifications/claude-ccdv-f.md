# Certification Overview: Claude Certified Developer – Foundations (CCDV-F)

- **Platform**: Anthropic Claude
- **Exam Code**: CCDV-F
- **Target Audience**: Developers, prompt engineers, and AI architects building production systems with Claude Messages API, Claude Agent SDK, Model Context Protocol (MCP), and Claude Code.
- **Duration**: 90 Minutes
- **Question Format**: 100 questions in practice bank
- **Passing Score**: Scaled (~70-75%)

## Objectives Breakdown
1. Agents, Workflows & Claude Agent SDK (20%)
2. Claude API Mechanics, Prompt Caching & Batch API (20%)
3. Tools & Model Context Protocol (MCP) (20%)
4. Prompt & Context Engineering with XML Tagging (15%)
5. Security, Governance & Injection Defense (15%)
6. Model Optimization & Claude Code Environment (10%)
