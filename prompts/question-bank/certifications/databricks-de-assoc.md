# Certification Overview: Databricks Certified Data Engineer Associate

- **Platform**: Databricks
- **Exam Code**: DE-ASSOC
- **Target Audience**: Data engineers implementing data pipelines, Lakehouse architecture, Unity Catalog governance, and automated CI/CD workflows using Apache Spark, Delta Lake, and Lakeflow Jobs.
- **Duration**: 90 Minutes
- **Question Format**: 45 questions on real exam / 100 questions in practice bank
- **Passing Score**: Scaled psychometric evaluation (~70%)

## Objectives Breakdown
1. Databricks Intelligence Platform (6%)
2. Data Ingestion & Loading (Auto Loader, COPY INTO) (21%)
3. Data Transformation & Modeling (Spark SQL, Delta Lake, MERGE INTO) (22%)
4. Working with Lakeflow Jobs (Orchestration, Retries, Parameters) (16%)
5. Implementing CI/CD & Asset Bundles (DABs) (10%)
6. Troubleshooting, Monitoring & Optimization (Photon, Z-ORDER, VACUUM) (10%)
7. Governance & Security (Unity Catalog 3-level namespace) (15%)
