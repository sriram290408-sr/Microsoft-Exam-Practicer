# Certification Overview: SnowPro Core Certification (COF-C03)

- **Platform**: Snowflake
- **Exam Code**: COF-C03
- **Target Audience**: Data practitioners, engineers, and architects managing storage, compute, and cloud services in the Snowflake Data Cloud.
- **Duration**: 115 Minutes
- **Question Format**: 100 questions
- **Passing Score**: 750 / 1000 (~75%)

## Objectives Breakdown
1. Snowflake Architecture and Features (31%)
2. Data Querying and Performance (21%)
3. Account Access and Governance (20%)
4. Data Loading and Transformation (18%)
5. Data Sharing and Collaboration (10%)
